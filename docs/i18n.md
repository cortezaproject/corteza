# Internationalization (i18n)

## Rules

- **No hardcoded UI strings** — all user-facing text must use translations
- Locale files live in `locale/en/corteza-webapp-{appname}/` organized per view

## Locale File Structure

```
locale/en/
├── corteza-webapp-one/
│   └── dashboard.yaml
├── corteza-webapp-compose/
│   ├── namespace.yaml
│   ├── module.yaml
│   ├── page.yaml
│   └── ...
└── corteza-webapp-taq/
    ├── dashboard.yaml
    ├── builder.yaml
    └── ...
```

## Usage

### In templates

```vue
<template>
  {{ $t('dashboard.title') }}
  {{ $t('namespace.delete.confirm', { name: ns.name }) }}
</template>
```

### In `<script setup>`

```vue
<script setup>
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
toast.add({ summary: t('builder.toast.saved.summary') })
</script>
```

### Interpolation

Use `{name}` placeholders in YAML, pass values as second argument:

```yaml
# locale file
delete:
  confirm: 'Delete {name}?'
```

```vue
$t('delete.confirm', { name: item.name })
```
