# What is Human

Human is an open platform for building the software a team runs on: the data it
keeps, the screens people work in, the automations that move work along, and
the AI agents that help with it. You assemble these in the browser, and they
all share one permission model.

## What you can build

- **Apps.** Describe your data as modules and fields, then lay out record lists,
  forms, charts and calendars on pages. A CRM, a case tracker or an asset
  register is an afternoon's work.
- **Automations.** TAQs (Trigger Action Queries) run when a record
  changes, on a schedule, or when something calls them.
- **Agents.** Give a model instructions, tools and topics to know about. People
  talk to agents in the Assistant, and automations and chatbots can run them
  too.
- **Chatbots.** Embed a chatbot on your website that follows a scripted journey
  and hands off to an agent or a person.

## How it fits together

Everything lives on one server with one database. The web app at `/` is where
people sign in and open the apps they use. Builders work in the same web app,
in the sections for apps, automation and agents. Administrators manage users,
roles and permissions there too.

Every action, whether a person clicks it, an automation runs it or an agent
calls it, is checked against the same role-based permissions. An agent can
never do more than the person it acts for.
